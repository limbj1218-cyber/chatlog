# 루나봇 StarLight(NeonJS) 설치 가이드

메신저봇R 판(`bot/루나봇.js`, `bot/루나봇로더.js`)은 **그대로 남아 있다.** 옮기다 안 되면 메신저봇R 쪽 루나봇을 다시 켜면 된다.

## 1. StarLight 설치

- **GitHub 판 APK**를 받는다: https://github.com/mooner1022/StarLight/releases (2026-11-14 기준 v1.2.0)
  - Play 스토어 판은 일부 자바 기능을 막아 두고, 데이터가 앱을 지우면 같이 지워진다 → GitHub 판 권장
- 처음 켜면 묻는 권한을 모두 허용한다: **알림 접근**, **다른 앱 위에 표시**, **모든 파일 접근**
- 설정 → 일반 → **배터리 최적화 예외**도 켜 둔다 (안 켜면 화면이 꺼졌을 때 알림이 늦거나 멈춘다)

## 2. 메신저봇R 의 루나봇 끄기

두 앱이 같이 켜져 있으면 루나 방에서 둘 다 답한다. 메신저봇R 에서 **루나봇만 끈다** (지우지 말 것 — 되돌릴 때 쓴다).

## 3. 프로젝트 만들기

StarLight → 프로젝트 → **새 프로젝트**

| 항목 | 값 |
|---|---|
| 이름 | `루나봇` |
| 언어 | **NeonJS** |
| API 방식 | **StarLight 원본** + **메신저봇 API2** (둘 다 체크) |
| 받을 이벤트 | `starlight.message.create` (onMessage) |

만든 뒤 **수정**을 눌러 메인 스크립트 내용을 전부 지우고 `bot/starlight/루나봇로더.js` 를 통째로 붙여넣는다.
→ **컴파일** → 켜기.

- 컴파일할 때 로더가 깃헙에서 본체(`bot/starlight/루나봇.js`)를 받아 프로젝트 폴더에 `luna_body.js` 로 둔다.
  인터넷이 되는 상태에서 컴파일할 것. 한 번 받으면 그 뒤로는 깃헙이 안 돼도 돈다.

## 4. 데이터 옮기기 (재련 기록·등록 명령어·클로드 토큰)

메신저봇R 판은 `luna_Database.json`, `claude_token.txt` 를 메신저봇 앱 폴더에 두었다
(보통 `내장 메모리/Android/data/com.xfl.msgbot/files/`).

1. 파일 관리자로 이 두 파일을 **`내장 메모리/Download/`** 에 복사한다
   (안드로이드 11 이상은 Android/data 가 안 보일 수 있다 — 그러면 PC 에 연결해서 복사)
2. 루나 방에서 관리자가 `/루나가져오기` → 두 파일을 StarLight 프로젝트의 data 폴더로 가져오고 다시 불러온다
   - 다른 곳에 두었으면 `/루나가져오기 /sdcard/폴더경로`
   - 이미 있던 StarLight 쪽 파일은 `.bak` 으로 남긴다
3. `/랭킹` 으로 기록이 이어졌는지 본다

> 데이터를 안 옮겨도 봇은 돈다. 이때는 본체에 들어 있는 11/14 랭킹 손질(`luna-ranking-2026-11-14`)이
> 랭킹 이름 3명이 말한 뒤 저절로 들어간다. 등록 명령어·클로드 토큰은 새로 넣어야 한다.

## 5. 확인할 것

| 방에서 | 볼 것 |
|---|---|
| `/루나로더` | 본체 버전 ✅, 데이터 폴더, 알림 시계 `setInterval` |
| `/내정보` | `보낸 사람 hash: 있음 ✅` — 없으면 사람 구분이 대화명 기준으로 돈다 |
| `재련가즈아` (본인) | **옛 단계에서 이어지는지** — 이어지면 StarLight 의 hash 가 메신저봇R 과 같은 값이다. 1부터 새로 시작하면 hash 가 다르다는 뜻이니 알려 줄 것 (이름으로 이어 붙이는 손질이 필요) |
| `/알림 (2분 뒤) 테스트` → `0` → `오늘만` | 그 시각에 "⏰ 테스트" 가 오는지 |
| `..` → `.안녕` | 1~2분 뒤 클로드 답이 오는지 (토큰을 가져왔을 때) |

카톡 없이 시험하려면 프로젝트의 **디버그** 방을 쓴다. 디버그 방 설정에서 **방 이름을 `루나`** 로 바꿔야 봇이 반응한다
(디버그 방에서는 hash 가 없어 대화명 기준으로 기록된다).

## 6. 업데이트

본체를 고쳐 깃헙에 올리면 루나 방에서 관리자가 `/루나업데이트`.
새 본체를 먼저 읽어 보고 문제없을 때만 바꾸며, 옛 본체는 `luna_body_prev.js` 로 남긴다.

## 7. 되돌리기

StarLight 의 루나봇 프로젝트를 끄고 메신저봇R 의 루나봇을 다시 켠다.
StarLight 에서 쌓인 기록은 StarLight 프로젝트의 `data/luna_Database.json` 에 있으니, 필요하면 메신저봇R 폴더로 다시 복사한다.
