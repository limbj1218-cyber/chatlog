# 🖥️ 시놀로지 DS718+ 에 안드로이드(BlissOS) 올려서 카톡봇 돌리기

폰 없이 NAS만으로 카톡봇을 돌리기 위한 가이드입니다.
**DS718+ 기준**으로 작성했으며, 다른 모델은 CPU/RAM 조건만 다릅니다.

---

## ⚠️ 시작 전에 꼭 읽어주세요

이 방법은 **성공이 보장되지 않습니다.** DS718+ 의 구조적 한계 때문입니다.

| 항목 | 상태 |
|---|---|
| ARM 앱 변환 (카톡 APK) | ✅ BlissOS 내장 변환기로 해결 |
| CPU 호환 (x86_64-v2) | ✅ Celeron J3455 충족 |
| RAM | ⚠️ **6GB 증설 필수** (기본 2GB로는 불가) |
| **GPU 가속** | ❌ **VMM은 GPU 패스스루 미지원** → 소프트웨어 렌더링, 매우 느림 |
| CPU 성능 | ❌ 저전력 셀러론이 NAS 본업과 함께 부담 |
| 알림(FCM) 수신 | ⚠️ 여기서 막히면 봇이 동작 불가 |

**그래서 아래 3개 "관문"에서 막히면 즉시 중단하는 것을 권합니다.**
시간을 무한정 쓰지 않기 위한 안전장치입니다.

- 🚧 **관문 A** (6단계) — 구글 로그인 성공 여부
- 🚧 **관문 B** (7단계) — 카카오톡 설치·로그인 성공 여부
- 🚧 **관문 C** (8단계) — **알림이 실제로 뜨는지** ← 가장 중요

---

## 0. 준비물

- **4GB DDR3L SODIMM 1866MHz** 메모리 1개 (2만 원 내외) — DS718+ 는 최대 6GB
- **BlissOS ISO** — `x86_64-v2` + **GApps 포함** 버전 (GApps 없으면 관문 C 에서 무조건 실패)
  - 다운로드: https://blissos.org 또는 SourceForge
  - 권장: **Bliss OS 15.9.x (x86_64-v2, GApps)** — 문서화가 가장 잘 되어 있음
- 카톡 봇 계정으로 쓸 카카오톡 계정 (본인 계정 말고 별도 권장)
- 여유 시간 2~3시간

---

## 1단계 — RAM 증설 (필수)

기본 2GB 상태로는 VM 을 띄울 수 없습니다.

1. NAS 전원 끄고 전원선 분리
2. 드라이브 베이 쪽 하단 메모리 슬롯에 4GB DDR3L 장착 (총 6GB)
3. 부팅 후 **DSM → 제어판 → 정보 센터** 에서 6GB 인식 확인
4. **DSM → 지원 센터 → 메모리 테스트** 로 정상 동작 확인 권장

> 💡 시놀로지 공식 지원은 6GB 까지입니다. 비공식으로 8GB 이상 인식되는 사례도 있으나 권장하지 않습니다.

---

## 2단계 — ISO 준비

1. PC 에서 BlissOS ISO 다운로드 (`x86_64-v2`, GApps 포함)
2. **File Station** 으로 NAS 에 업로드 (예: `/homes/admin/iso/`)

---

## 3단계 — VMM 설치 & VM 생성

**패키지 센터 → Virtual Machine Manager** 설치 (Btrfs 볼륨 필요)

**가상 컴퓨터 → 생성 → Linux** 선택 후:

| 설정 | 값 | 비고 |
|---|---|---|
| CPU 코어 | **3** | 4개 다 주면 NAS 본업이 느려짐 |
| 메모리 | **3072 MB** (3GB) | 6GB 중 절반. DSM 에 최소 2GB 는 남겨둘 것 |
| 가상 디스크 | **32 GB 이상** | 64GB 권장 |
| 네트워크 | 기본값 (VirtIO) | |
| **부팅 방식** | **UEFI** | ⚠️ 중요 — Legacy BIOS 로는 설치가 꼬입니다 |
| 비디오 카드 | 기본값 | 선택지가 있으면 `vmvga` 또는 `std` |
| ISO 파일 | 1단계에서 올린 BlissOS ISO | **부팅 순서 1번** |
| 자동 시작 | 켜기 | NAS 재부팅 시 봇도 자동 복귀 |

생성 후 **전원 켜기 → 연결** 로 콘솔 화면을 엽니다.

---

## 4단계 — BlissOS 설치

부팅 메뉴가 뜨면:

1. **Installation - Install Bliss OS to harddisk** 선택
2. 파티션 화면에서 **GPT 사용** 선택 (`Yes`)
3. 파티션을 아래처럼 만듭니다:

   | 파티션 | 크기 | 타입 | 용도 |
   |---|---|---|---|
   | 1번 | **512 MB** | `ef00` (EFI System) | 부트로더 |
   | 2번 | 나머지 전부 | Ext4, 이름 `android` | 시스템 |

4. 2번 파티션을 **Ext4 로 포맷** (`Yes`)
5. **GRUB 부트로더 설치** (`Yes`)
6. **`/system` 을 읽기·쓰기로 마운트** (`Yes`) ← ARM 변환기 동작에 필요
7. 설치 완료 후 **`Reboot` 하지 말고 전원 끄기**

**전원 끈 뒤 VM 설정 → ISO 파일 분리(마운트 해제)** 후 다시 켭니다.
(ISO 가 붙어 있으면 계속 설치 화면으로 부팅됩니다)

---

## 5단계 — 첫 부팅

GRUB 메뉴에서 **⚠️ 반드시 `No HW Acceleration` (또는 `Software Rendering`) 옵션을 선택**하세요.

> DS718+ 는 GPU 패스스루가 안 되므로, 기본 모드로 부팅하면 **검은 화면**에서 멈춥니다.

부팅이 되면 안드로이드 초기 설정 화면이 나옵니다. **매우 느립니다 (수 분 소요)** — 정상입니다.

### 🚧 여기서 화면이 안 뜨면
- GRUB 메뉴에서 `e` 를 눌러 커널 파라미터에 `nomodeset video=1024x768` 추가 후 부팅
- 그래도 안 되면 → **여기서 중단하고 대안으로** (맨 아래 참고)

---

## 6단계 — 🚧 관문 A: 구글 로그인

초기 설정에서 **Google 계정 로그인**을 진행합니다.

- ✅ 로그인 성공 → 다음 단계로
- ❌ "이 기기는 Play 프로토콜을 인증받지 않았습니다" → GApps 미포함 ISO 입니다. **GApps 포함 버전으로 다시 설치**하거나 여기서 중단

> Play 서비스가 정상 동작해야 8단계(알림)가 가능합니다. 이 단계를 건너뛰지 마세요.

---

## 7단계 — 🚧 관문 B: 카카오톡 설치

**Play 스토어에서 카카오톡 설치** (ARM 변환기가 자동으로 처리)

- ✅ 설치·실행·로그인 성공 → 다음 단계로
- ❌ 설치 불가 / 실행 즉시 종료 → ARM 변환 실패. **여기서 중단**

로그인 시 **본인 확인(SMS)** 이 필요하니 휴대폰 번호를 준비하세요.

---

## 8단계 — 🚧 관문 C: 알림 확인 (가장 중요)

**메신저봇R 은 카톡 "알림"을 읽어 동작합니다. 알림이 안 오면 모든 게 무의미합니다.**

1. VM 안 카카오톡에서 아무 채팅방의 **알림을 켭니다**
2. **다른 폰**에서 그 방으로 메시지를 보냅니다
3. VM 안드로이드 화면 상단에 **알림이 뜨는지 확인**

- ✅ 알림 뜸 → 성공! 9단계로
- ❌ 알림 안 뜸 → FCM 푸시가 동작하지 않는 것. **여기서 중단** (해결 난이도 매우 높음)

> 앱을 열어두면 메시지는 보이지만 **알림이 안 뜨는** 경우가 있습니다. 반드시 앱을 백그라운드로 두고 테스트하세요.

---

## 9단계 — 메신저봇R 설치

여기까지 왔다면 사실상 일반 안드로이드 폰과 같습니다.

1. VM 안드로이드에 **메신저봇R** 설치
2. **알림 접근 권한 / 저장소 권한** 허용
3. 설정 → 배터리 최적화 제외 (VM 이라도 설정해두면 안전)
4. 새 봇 생성 → 아래 로더 중 필요한 것 붙여넣기:
   - 단톡봇: `bot/로더.js`
   - 제련봇: `bot/제련봇로더.js`
   - 사건봇: `bot/사건봇로더.js`
5. 컴파일 → 전원 ON
6. 다른 폰에서 `/로더` 또는 `핑` 으로 테스트

---

## 🔧 문제 해결

| 증상 | 조치 |
|---|---|
| 부팅 시 검은 화면 | GRUB 에서 `No HW Acceleration` 선택. 안 되면 `nomodeset` 추가 |
| 설치 화면만 반복 | VM 설정에서 **ISO 마운트 해제** 안 함 |
| 마우스가 어긋남 | 해상도를 `1024x768` 로 낮춰서 부팅 |
| 극도로 느림 | 정상입니다 (GPU 가속 없음). CPU 코어를 3개로 늘려보되 NAS 부하 주의 |
| 네트워크 안 됨 | VM 네트워크를 VirtIO 로, 안 되면 e1000 으로 변경 |
| NAS 전체가 느려짐 | VM 메모리·코어를 줄이세요. DS718+ 는 여유가 많지 않습니다 |

---

## 🛟 막혔을 때의 대안

관문 A/B/C 중 하나라도 실패했다면 아래가 훨씬 빠릅니다.

1. **안 쓰는 미니PC / 구형 노트북에 BlissOS 설치**
   → GPU 가속이 되므로 VM 보다 훨씬 잘 돌아갑니다. 같은 4~9단계를 그대로 쓰면 됩니다.

2. **구형 안드로이드 폰 (3~5만 원)**
   → 지금 코드 그대로 즉시 동작. 전력 2W. 가장 확실합니다.

3. **폰 중계 + NAS 두뇌 구성**
   → 폰은 카톡 창구로만 두고, 봇 로직·데이터를 DS718+ Docker 로 이전.
     데이터가 NAS 에 안전하게 남고 개발도 훨씬 편해집니다.
